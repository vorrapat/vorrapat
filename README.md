## 💙 Finlove — Dating Application

Modern dating app using intelligent matching to build meaningful connections, with a focus on **usability, accessibility, and inclusive design**.

**🔗 [View Prototype on Figma](https://www.figma.com/design/upfg43zXyE4zPOxtfp2iBl/FINLOVE-UX-UI?node-id=0-1)**

| Problem | Solution |
|---|---|
| Irrelevant matches & complex UI hurt the user experience | Simplified user flow + intelligent matching to boost usability and accuracy |

**Key Features**
- 🧠 Hybrid Recommendation System (KNN + Cosine Similarity)
- 👤 Facial Recognition
- ⚡ High-performance API (Web & Android)
- 🗄️ MySQL Database

## 🩺 Telemedicine Application

Platform connecting patients with doctors via online consultation — because traditional healthcare access is often slow and inconvenient.

| Problem | Solution |
|---|---|
| Time-consuming, inconvenient access to care | Remote booking, chat & video consults — care anytime, anywhere |

**Key Features**
- 📅 Appointment Booking
- 💬 Real-time Chat
- 🎥 Video Consultation
- 👩‍⚕️ Doctor Profiles & Availability
- 🔔 Notifications
